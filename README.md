# Телеграм-бот «Учитель физики»

Бот отвечает на вопросы по физике за 7–11 класс простым языком, с примерами,
и решает задачи по шагам. Ученик может прислать текст, фото задачи или голосовое
сообщение. Бот отвечает на том языке, на котором ему написали: казахском,
русском или узбекском. Когда ученик спрашивает про курсы, бот показывает кнопки
с вашими ссылками (платформа, Instagram, TikTok, YouTube).

## Запуск (Windows)

1. Установите Python 3.11 или новее: https://www.python.org/downloads/
   При установке **обязательно поставьте галочку «Add python.exe to PATH»**.
2. Откройте файл `.env` и вставьте:
   - `TELEGRAM_BOT_TOKEN=` токен от @BotFather
   - `GEMINI_API_KEY=` ключ из https://aistudio.google.com/apikey
3. Откройте `school_info.py` и заполните ссылки и описание курсов.
4. Дважды щёлкните `run.bat`. При первом запуске библиотеки установятся сами.
   Появится надпись «Бот запущен», после этого напишите боту в Telegram.

Бот работает, пока открыто окно `run.bat` и включён компьютер. Чтобы он работал
круглосуточно, его нужно перенести на сервер (VPS или хостинг для Python).

## Файлы

| Файл | Что внутри |
|---|---|
| `.env` | секретные ключи (никому не показывайте) |
| `school_info.py` | ваши ссылки и информация о курсах |
| `prompts.py` | инструкция для ИИ: как объяснять, на каком языке отвечать |
| `bot.py` | код бота |

## Команды бота

- `/start` — приветствие
- `/links` — курсы и ссылки (кнопки)
- `/new` — начать новый диалог (бот забывает прошлые вопросы)
